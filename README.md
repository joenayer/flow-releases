# Pellin downloads

Public downloads for Pellin. For Android, choose the **arm64-v8a APK** for
modern Samsung phones, or **universal** for other supported devices. For
Windows, download **Pellin-Setup.exe**.

[Open releases](https://github.com/joenayer/flow-releases/releases)

Each Android APK is a standalone installer. Android may ask permission for
your browser or file manager to install unknown apps. Keep your existing
app and data if an installation fails.

The Windows installer is per-user and needs no administrator access. It is
unsigned, so SmartScreen will warn — choose **More info → Run anyway**.

Speech recognition runs on your device. On Android, first-launch setup
downloads the recommended Parakeet model and Silero pause detector after
you tap Download; Wi-Fi and about 1.8 GB of free space are recommended for
setup. The Windows installer bundles the recommended model, so Windows
setup works offline.

Preview signing certificate SHA-256: `55d12445242c1cdcc248f6bc5026aba624e73de2f47496f328d8affb7222126b`.

This repository stores public release downloads only. It does not contain
source code or signing keys.
