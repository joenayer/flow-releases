# Flow Android downloads

Public APK downloads for Flow Preview. Choose the **arm64-v8a APK** for modern Samsung phones, or **universal** for other supported devices.

[Open releases](https://github.com/joenayer/flow-releases/releases)

Each APK is a standalone installer. Android may ask permission for your browser or file manager to install unknown apps. Keep your existing app and data if an installation fails.

Speech recognition runs on your device. The first-launch setup downloads the recommended Parakeet model and Silero pause detector after you tap Download. Wi-Fi and about 1.8 GB of free space are recommended for setup.
